# HW4: работа с данными в Apache Spark под управлением YARN (team-17)

Продолжение ДЗ1-ДЗ3 на том же кластере из 4 машин: Apache Spark 3.5.9 на edge с раздачей библиотек через HDFS в контейнеры YARN, подключение к общему внешнему Hive Metastore, чтение CSV из HDFS, трансформации данных, сохранение в партиционированную Parquet-таблицу `hw4.revenue_by_city` и проверка ее чтения стандартным клиентом Beeline.

- [`INSTRUCTION.md`](INSTRUCTION.md) - инструкция по шагам: что делать руками, на какой ноде и под каким пользователем, как проверить. **начинать отсюда**
- [`deploy.sh`](deploy.sh) - те же шаги одним скриптом: запускается на edge под `team` (`bash deploy.sh`), можно перезапускать
