# HW3: развертывание Apache Hive (team-17)

Продолжение ДЗ1 и ДЗ2 на том же кластере из 4 машин: PostgreSQL 16 под метаданные на 01, отдельные сервисы Hive Metastore и HiveServer2 на edge, загрузка данных в партиционированную таблицу `hw3.sales` и одновременная работа нескольких клиентов Beeline. Веб-интерфейс HiveServer2 доступен на своем компьютере через SSH-туннель.

- [`INSTRUCTION.md`](INSTRUCTION.md) - инструкция по шагам: что делать руками, на какой ноде и под каким пользователем, как проверить. **начинать отсюда**
- [`deploy.sh`](deploy.sh) - те же шаги одним скриптом: запускается на edge под `team` (`bash deploy.sh` или `PG_PASS='...' bash deploy.sh`), можно перезапускать
- [`../hw1/lab/`](../hw1/lab/) - локальный стенд из ДЗ1; как поднять - [`../hw1/lab/README.md`](../hw1/lab/README.md)
